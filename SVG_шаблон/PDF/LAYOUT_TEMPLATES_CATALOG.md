## 1. Архитектура модульной сетки и правила верстки

Все 10 шаблонов построены на едином модульном шаге:
- **Базовый модуль (Sub-grid step):** `8 px` / `12 px`
- **Колоночные и строчные отступы (Gap):** `24 px` / `53 px` / `60 px`
- **Поля безопасности экрана (Safe Screen Margins):**
  - Минимальный внешний margin: `60 px` от края экрана
  - Симметричные центрированные поля: `169 px` / `188 px` / `302 px` / `560 px`
- **Типографическая привязка:** `leading-trim: both; text-edge: cap;` для точной визуальной посадки текстовых блоков по базовым линиям без паразитных межстрочных зазоров шрифта.
